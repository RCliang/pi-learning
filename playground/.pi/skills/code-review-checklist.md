# 代码审查清单

当执行代码审查时，按以下步骤进行：

## 1. 安全性检查
- 是否有硬编码的密钥/密码？
- 是否有 SQL 注入风险？
- 是否有 XSS 风险？

## 2. 错误处理
- 异步操作是否有 try/catch？
- 边界条件是否处理？
- 错误信息是否友好？

## 3. 性能
- 是否有 N+1 查询？
- 是否有不必要的大对象拷贝？
- 循环是否可以优化？

## 4. 可读性
- 命名是否清晰？
- 函数是否过长（>50 行需关注）？
- 是否有重复代码？

输出格式：按【严重】【警告】【建议】三级分类报告问题。
